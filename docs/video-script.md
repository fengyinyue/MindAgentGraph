# MindAgentGraph 宣传视频稿

---

## 视频定位

- 时长：3-5 分钟
- 风格：深色工作台、节点图流动、精简克制，像 Unreal Blueprint 的宣传片但更偏开发者工具
- 目标观众：AI 辅助编程用户、独立开发者、技术负责人
- 核心信息：把 AI 工作从"聊天"升级为"结构化节点规划与执行"

---

## 分镜脚本

### 场景 0 · 开场钩子（0:00 - 0:25）

**画面**：快速剪辑——聊天窗口里 AI 生成了一大段代码，复制粘贴，报错，再问，上下文乱了，AI 开始改不该改的文件，开发者一脸疲惫。

**旁白**：
> 你跟 AI 聊了 300 轮，上下文烂了。它开始修改你没让改的文件，忘记了你第 50 轮说过的话。你复制粘贴，来回切换，项目越大，越像在和一个失忆的实习生合作。

**画面**：屏幕一黑。

**标题浮现**：MindAgentGraph

**旁白**：
> 如果把 AI 的工作方式，从"聊天"改成"节点图"，会怎样？

---

### 场景 1 · 产品登场（0:25 - 0:50）

**画面**：深色画布从中央展开，节点逐个浮现、连线自动生长。Planning 节点 → Prompt 节点 → Code 节点，形成一个清晰的 DAG 流。

**旁白**：
> MindAgentGraph —— 一个节点式 AI 创作规划工具。
>
> 每个节点，是 AI 的一个思维单元。有独立的目标、Prompt、记忆、文件范围和上下文边界。
>
> 连线，是依赖关系。图结构，就是你的项目计划。

**画面**：镜头缓慢推进，画布上节点闪烁执行，数据沿连线流动。

---

### 场景 2 · 核心演示：Planning → Explain → Generate Nodes（0:50 - 2:00）

**画面**：用户在画布上创建一个 Planning 节点，输入目标"做一个番茄钟软件"。

**旁白**：
> 你不需要从零开始写 Prompt。创建一个 Planning 节点，写下目标。

**画面**：右键 → Explain。节点开始执行，右侧面板实时显示生成的结构化规划文本——产品目标、核心模块、交互流程、实现顺序。

**旁白**：
> Explain —— AI 先生成一份可读、可审查的规划文本。不是直接跳到代码，而是先把"要做什么"讲清楚。

**画面**：用户浏览规划文本，修改了两处，然后点击 "Generate Nodes"。

**旁白**：
> 你可以审查、修改，然后一键展开成子节点图。

**画面**：Planning 节点下游自动生成 6 个子节点——产品需求、UI/交互设计、计时状态机、设置与持久化、测试验收、Code: 实现番茄钟——节点之间自动连线。

**旁白**：
> 需求、设计、状态机、持久化、测试、代码实现——每个模块一个节点，依赖关系一目了然。你审查、调整，然后逐个执行。

---

### 场景 3 · 节点级上下文控制（2:00 - 2:30）

**画面**：点击 Code 节点，右侧检查器展开——purpose、systemPrompt、memoryRef、fileScope（允许访问的文件范围）、contextMode、上游节点输出。

**旁白**：
> 这是 MindAgentGraph 的核心：每个节点有自己的上下文边界。
>
> Code 节点只看到你允许它看的文件范围。它继承上游节点的输出——需求文档、状态设计、接口约定——而不是盲目猜测你要什么。

**画面**：Code 节点执行，注入上游规划输出 + FileScope，精确修改目标文件。执行日志在底部面板实时滚动。

**旁白**：
> AI 在节点的边界内工作，不污染全局上下文。你知道 AI 当前在哪个节点、用了什么上下文、产生了什么输出。

---

### 场景 4 · DAG 顺序执行（2:30 - 2:55）

**画面**：回到画布，展示一个完整 DAG——Project Scan → Code Analysis → Planning → Prompt × 3 → Code × 2。节点按依赖顺序从上游到下游逐个高亮执行。

**旁白**：
> 多个节点？DAG 按依赖顺序批量执行。
>
> 上游节点的输出自动流入下游。先分析项目结构，再理解代码，再制定方案，最后才动手改——每一步都可追踪。
>
> 你可以随时暂停、调整、重跑单个节点。不用从头再来一遍。

---

### 场景 5 · 项目保存与工程化（2:55 - 3:15）

**画面**：展示 `.mag` 项目文件夹结构——JSON 存图、Markdown 存记忆、assets 目录。展示保存/打开流程。在 VS Code 中打开同一个 `.mag` 文件夹，显示 Git diff。

**旁白**：
> 项目保存为 `.mag` 工程文件夹。图结构是 JSON，记忆是 Markdown，全部 Git 友好。
>
> 你的规划、执行记录、AI 输出——全部跟着仓库走。团队可以 review 节点图，就像 review 代码一样。

---

### 场景 6 · 适用场景（3:15 - 3:45）

**画面**：三个场景快速切换——

1. 独立开发者规划一个 Unreal 游戏模块（HUD 系统、战斗逻辑、存档机制），Planning 节点展开为 Blueprint 拆解图。
2. 技术负责人在画布上拆解"微服务拆分方案"——Project Scan 扫描现有项目，Code Analysis 分析耦合点，Planning 输出迁移方案。
3. 创作者在画布上组织小说设定——世界观节点、角色节点、章节节点，Memory 节点存储设定细节，Prompt 节点辅助写作。

**旁白**：
> 游戏开发、软件架构、创作规划——任何需要结构化的 AI 协作场景，MindAgentGraph 都能帮你把"一团乱麻"变成"一张蓝图"。

---

### 场景 7 · 收尾 + CTA（3:45 - 4:15）

**画面**：回到空画布，一个节点从中央浮现，上面写着你的项目目标。缓缓拉远，画布上星辰般的节点图铺展开来。

**旁白**：
> 我们相信，AI 不应该只是一个聊天框。
>
> 它应该是你手中的蓝图工具——让你的想法有结构，让 AI 的执行有边界，让复杂项目的每一步都可看见、可追踪、可迭代。

**画面**：GitHub 仓库地址浮现。MindAgentGraph logo。

**旁白**：
> MindAgentGraph，开源、本地优先、Git 友好。
>
> GitHub 仓库在视频简介里。MVP 阶段已经可跑——欢迎来试，来提 issue，来一起把 AI 的工作方式从"聊天"升级为"结构化"。

**画面**：最后一行字——

> "Stop chatting. Start building."

## 制作建议

### 画面风格
- 全程深色主题（#0f0f0f 基底），节点用暗蓝/暗紫色调
- 节点连线用细线 + 流动粒子效果，表示数据/上下文传递
- 文字信息用无衬线字体，克制不花哨
- 避免过度动画，保持开发者工具的严肃感

### 声音
- 旁白用沉稳、清晰的男声或女声，节奏平缓
- 背景音乐：低沉的电子/ambient，类似 Unreal Engine 宣传片的配乐风格
- 关键节点执行时加微弱音效反馈（非必需）

### 录制
- 直接录屏软件界面操作
- 可以预先准备好几个 Demo 项目（番茄钟、微服务拆解、游戏模块规划）
- Planning → Explain → Generate Nodes → Code 执行流程一镜到底最好

### 时长控制
- 主视频控制在 4 分钟以内
- 可以另剪一个 60 秒快速版给社交媒体
